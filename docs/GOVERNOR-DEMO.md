# การนำเสนอผู้ว่าราชการจังหวัดเชียงใหม่ · Governor demonstration runbook

ใช้คู่กับ https://cnx.nonarkara.org/cnx — ตรวจตามรายการนี้ก่อนเข้าห้อง 30 นาที

## ก่อนเข้าห้อง (30 นาที) · Before the meeting

1. เปิดหน้าเว็บบนเครื่องที่จะใช้จริง มุมซ้ายบนต้องเห็น `v1.x.x · <sha>` ตรงกับรุ่นล่าสุด
2. ตรวจ `https://cnx.nonarkara.org/api/cnx/build` — commit ตรงกับที่แจ้งไว้
3. ดูแผง **เฝ้าระวังทั้งจังหวัด** ด้านขวา: ระบบที่ "ไม่มีข้อมูล" กี่ระบบ — ถ้ามากกว่าปกติ (เช่น ฝน/ระดับน้ำ) ให้ตรวจว่า relay บน Mac ยังทำงาน (`launchctl list | grep cnx`)
4. แถบพยากรณ์ใต้แผนที่ต้องแสดงวันเวลา (ไม่ใช่ "กำลังโหลด…") — ถ้าไม่ขึ้นใน 1 นาที ให้รีเฟรช
5. ปุ่ม **EN / ไทย** มุมขวาบน ตั้งเป็นภาษาไทย
6. เตรียมแผนสำรอง: ภาพหน้าจอ `docs/audit/<วันที่>/screenshots/` และไฟล์ PDF สรุปผู้ว่าฯ (ปุ่ม **สรุปผู้ว่าฯ** → พิมพ์/บันทึก PDF)
7. ถ้าอินเทอร์เน็ตห้องประชุมช้า: ใช้ hotspot มือถือ — บอร์ดใช้ข้อมูลประมาณ 2–4 MB ต่อการเปิด

## ลำดับการนำเสนอ 7 นาที · The 7-minute story

| นาที | แสดง | ประเด็นที่พูด |
|---|---|---|
| 0–1 | หน้าแรก: แถบสถานะบนสุด (น้ำ · อากาศ · ไฟ · การบิน) | "จังหวัดตอนนี้เป็นอย่างไร" ใน 4 ตัวเลข ทุกตัวบอกเวลาที่วัดและแหล่งที่มา |
| 1–2 | แผง **48 ชั่วโมงข้างหน้า** | อำเภอที่แบบจำลองคาดฝนหนัก/ฝุ่นสูง เวลาที่หนักสุด และ**ศูนย์พักพิงทางการ**ของอำเภอนั้น |
| 2–3 | กด **ดูบนแผนที่** | แผนที่บินไปที่อำเภอ แสดงศูนย์พักพิง (วงกลมทึบ = พิกัดอาคารจริง, วงกลมโปร่ง = ตำแหน่งโดยประมาณ) |
| 3–4 | แถบเวลาใต้แผนที่ → กด ▶ | ลมเคลื่อนที่ตามพยากรณ์ 48 ชม. สลับ **ลมพาควัน ~1.5 กม.** และชั้น **ฝน** / **PM2.5** |
| 4–5 | ชั้นข้อมูล → แนวควัน (Plumes) | ควันจากจุดความร้อนดาวเทียม NASA ไหลไปทางไหนใน 6 ชม. — เส้นโค้งตามลมพยากรณ์ |
| 5–6 | ปุ่ม **สรุปผู้ว่าฯ** | ข้อความพร้อมส่ง LINE พร้อมข้อสั่งการ — รวมข้อสั่งการจากพยากรณ์ (ระบุว่าเป็นแบบจำลอง) |
| 6–7 | ปุ่ม **ติดต่อฉุกเฉิน** และ **เฝ้าระวังทั้งจังหวัด** | ทุกระบบแสดงทุกรอบ ระบบที่ล่มจะแสดงว่าล่ม — "ไม่มีข้อมูล ไม่ใช่ปลอดภัย" |

**ประโยคที่ควรพูด:** "ระบบนี้ไม่เคยบอกว่าปลอดภัยเมื่อไม่มีข้อมูล — ข้อมูลที่ขาดจะแสดงว่าขาดเสมอ"

## คำถามที่อาจถูกถาม · Likely questions

- **ข้อมูลมาจากไหน?** กรมทรัพยากรน้ำ/สสน. (ThaiWater) ระดับน้ำและฝน, NASA FIRMS จุดความร้อน, DustBoy มช. และ คพ. ฝุ่น, Open-Meteo/CAMS พยากรณ์, Google Flood Hub, สำนักงานจังหวัดเชียงใหม่ (ศูนย์พักพิง) — ดู `docs/SOURCES.md`
- **แม่นแค่ไหน?** ค่าวัดเป็นค่าจริงจากสถานี; พยากรณ์เป็นแบบจำลองกริด ~30 กม. ใช้เตรียมพร้อม ไม่ใช่แทนประกาศทางการของกรมอุตุฯ/ปภ.
- **ศูนย์พักพิงถูกตำแหน่งไหม?** 177 แห่งจากรายชื่อทางการ ตำแหน่งตรงอาคารเฉพาะที่ระบุว่า "ตำแหน่งจากแผนที่" ที่เหลือเป็นโดยประมาณ — จังหวัดส่งพิกัดยืนยันได้ผ่านไฟล์ `public/data/cnx/shelters-to-verify.csv` (ดู `docs/SHELTERS.md`)
- **ปลอดภัยไหม?** ไม่มีข้อมูลส่วนบุคคล, เขียนข้อมูลได้เฉพาะ relay ที่มีรหัสลับ, CSP แบบ nonce, จำกัดอัตราการเรียกต่อ IP, HTTPS/HSTS — ดู `docs/SECURITY.md`

## ถ้ามีปัญหาระหว่างนำเสนอ · If something breaks live

| อาการ | ทำอย่างไร |
|---|---|
| แผนที่ขาว/ไม่ขึ้น | รีเฟรช 1 ครั้ง; ถ้ายังไม่ขึ้น เปลี่ยนแผนที่พื้นฐานเป็น Terrain ในชั้นข้อมูล |
| แถบพยากรณ์ "ไม่มีข้อมูล" | พูดตรง ๆ: "แบบจำลองไม่ตอบในรอบนี้ ระบบจึงไม่แสดง — ไม่ใช่การบอกว่าปลอดภัย" แล้วไปต่อ |
| ทั้งเว็บไม่ขึ้น | ใช้ PDF สรุปผู้ว่าฯ และภาพหน้าจอสำรอง |
| ต้องย้อนรุ่น | `npx wrangler rollback -c wrangler.cnx.jsonc` (ผู้ดูแลระบบ) |

# Usability walkthrough (Mama rule) · การทดสอบกับผู้ใช้จริง 20 นาที

Palette's Mama rule: give the board to an older, non-technical first-time
user. Give a goal, not instructions. Do this with **two** people from the
governor's office (e.g. a duty officer and a senior staff member) before
the meeting. A model cannot do this step — record what real people did.

**วิธีทำ:** เปิดหน้าเว็บให้ผู้ทดสอบ อ่านโจทย์ทีละข้อ ห้ามบอกว่าต้องกดตรงไหน
จับเวลาและจดว่าลังเลตรงไหน ทำผิดอะไร และแก้ตัวเองได้หรือไม่

| # | โจทย์ (อ่านให้ฟัง) | สำเร็จเมื่อ | เวลา | ลังเล/ผิดพลาด |
|---|---|---|---|---|
| 1 | "ตอนนี้แม่น้ำปิงในเมืองน่าห่วงไหม" | บอกระดับน้ำเทียบตลิ่งได้ | | |
| 2 | "อีก 2 วัน อำเภอไหนน่าห่วงเรื่องฝนหรือฝุ่นที่สุด" | ชี้อำเภอจากแผง 48 ชั่วโมงข้างหน้า | | |
| 3 | "ถ้าต้องอพยพคนในอำเภอนั้น จะพาไปที่ไหน" | บอกชื่อศูนย์พักพิงและจำนวนที่รับได้ | | |
| 4 | "พรุ่งนี้เช้าลมพัดไปทางไหน" | ใช้แถบเวลาเลื่อนไปพรุ่งนี้เช้าแล้วบอกทิศ | | |
| 5 | "ส่งสรุปสถานการณ์ให้ผู้ว่าฯ ทาง LINE" | เปิดสรุปผู้ว่าฯ และคัดลอกข้อความได้ | | |
| 6 | "ข้อมูลไหนตอนนี้ใช้ไม่ได้" | ชี้ระบบที่ "ไม่มีข้อมูล" ได้ | | |
| 7 | (ความผิดพลาดปกติ) ให้กดปิดแผงโดยไม่ตั้งใจ แล้ว "กลับไปที่เดิม" | กลับมาได้เองโดยไม่ต้องช่วย | | |

บันทึกผล: **ผ่าน / ไม่ผ่าน / ไม่ได้ทดสอบ** ต่อข้อ พร้อมคำพูดของผู้ทดสอบ
ส่งผลกลับมาเพื่อแก้ไขสิ่งที่คนจริงติด — แก้ข้อที่คนทำไม่ได้ก่อนเรื่องความสวยงาม
